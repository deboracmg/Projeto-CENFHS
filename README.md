# 🏛️ Sistema de Gestão Institucional

Aplicação web desenvolvida para apoiar a organização de informações e as atividades administrativas de uma instituição, integrando um site institucional e um painel de gestão.

## ⚙️ Tecnologias utilizadas

### Back-end
Desenvolvido com **Python e Django**, responsáveis pelas regras de negócio, rotas, autenticação e acesso aos dados pelo Django ORM.

### Front-end
Construído com **HTML5, CSS3 e JavaScript**, utilizando **Django Templates** para renderização das páginas e **Font Awesome** para os ícones.

### Banco de dados
O **MySQL** armazena e organiza os dados relacionais da aplicação.

## ✨ Recursos previstos

- Site institucional público.
- Gestão de cadastros e informações administrativas.
- Autenticação e controle de acesso.
- Dashboard e relatórios.
- Gerenciamento de imagens do site.
